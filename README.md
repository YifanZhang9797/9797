# 合规爬虫：东方财富股吧寒武纪（688256）

该仓库提供一个**合规导向**的 Python 脚本，用于抓取股吧帖子标题，并完成：

- 时间范围过滤：`2024-09-01` 到 `2025-09-30`
- 按交易日过滤（内置 2024/2025 节假日休市）
- 每个交易日随机抽样最多 100 条

> 说明：脚本使用东方财富股吧常见内部接口，站点可能调整参数或反爬策略。请在使用前确认你有权抓取并遵守 robots.txt / 服务条款及相关法律法规。

## 运行环境

- Python 3.10+
- 无第三方依赖（仅标准库）

## 快速开始

```bash
python eastmoney_guba_crawler.py \
  --code 688256 \
  --start 2024-09-01 \
  --end 2025-09-30 \
  --per-day 100 \
  --seed 688256 \
  --out-csv output/cambricon_688256_titles_sampled.csv \
  --out-jsonl output/cambricon_688256_titles_sampled.jsonl
```

## 常用参数

- `--max-pages`：最多抓取页数（默认 800）
- `--sleep`：每页请求间隔秒数（默认 0.25，建议不要调得太低）
- `--per-day`：每日抽样条数（默认 100）
- `--seed`：随机种子，保证可复现

## 输出格式

CSV 字段：

- `trade_date`
- `published_at`
- `post_id`
- `title`
- `url`

同样内容会输出 JSONL（每行一条 JSON）。
